## Overview
Pennyway is a standalone desktop application that automatically synchronizes, categorizes, and provides deep insights into your financial accounts.

It is built as a **local-first** application. Your sensitive financial data (like transaction history and private keys) never leaves your machine. The app only accesses a central server to verify your software license.

## 💾 Download & Install
1. Head over to the **[Releases](https://github.com/stiassny/pennyway_releases/releases)** page on this repository.
2. Under the **latest release**, download the `Pennyway Setup X.X.X.exe` file.
3. Run the `.exe` file on your Windows machine to install Pennyway.

## ⚠️ Important Note on Installation (Windows SmartScreen)
Because Pennyway is currently published without a commercial code-signing certificate, Windows may flag the installer as "unrecognized" the first time you run it.

**To successfully install:**
1. When the "Windows protected your PC" blue prompt appears, click on **More info**.
2. Click the **Run anyway** button that appears at the bottom.
3. The installer will proceed normally.

## 🔄 Auto-Updates
Pennyway handles updates automatically! Once installed, the application will periodically check this repository for newer versions. When a new update is detected and downloaded, Pennyway will prompt you to restart the application to apply the update seamlessly.
